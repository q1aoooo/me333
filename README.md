# ME<333*

把你想看的人，自動放在畫面中間的小工具。
不管是自己的跳舞影片，還是偶像的舞台、練習室影片，多人同框時點一下想追蹤的人，畫面就會一路跟著他、放在正中間，再加上濾鏡和調色，輸出成可以直接發的影片。

👉 線上使用：https://q1aoooo.github.io/me333/

## 為什麼做這個

平常跳舞拍完影片，都要在剪映裡一格一格手動設關鍵影格，讓自己保持在畫面中間，很花時間。
看到很多人用 AI 做小工具幫自己省事，就想試著做一個。
做好之後發現剪偶像影片時也用得到，所以把用途從跳舞影片擴大成「追蹤任何想看的人」。

## 功能

- **點選要追蹤的人**：多人同框時，點一下想追蹤的人就好（自己或偶像都可以）
- **自動置中**：畫面跟著人平滑移動，可以調放大倍率、跟隨速度、要不要上下跟隨
- **選擇畫面比例**：原比例、9:16、1:1、3:4，方便發到不同平台
- **調整人物上下位置**：可以用滑桿，或直接在預覽畫面上下拖曳，決定人在畫面裡偏上還是偏下
- **鎖定追蹤**：選好的人會一直鎖定，他暫時不見時不會改跟別人，畫面停在原地；也可以在不同時間點重新選人
- **手動關鍵影格**：人物還沒出現或跟丟的片段，可以自己拖曳畫面設定關鍵影格，畫面會在關鍵影格之間平滑移動；追蹤到人之後再自動接手
- **濾鏡與調色**：原色、清新、暖色、冷色、復古、黑白，另外可以調曝光、對比、色溫、色調
- **輸出 mp4**：逐格處理後輸出，剪映、Wink 都能直接讀

## 使用方式

1. 用新版 Chrome 或 Safari 打開網頁（Chrome 最順）
2. 把影片拖進來
3. 暫停在看得到那個人的畫面，按「點選要追蹤的人」，點一下他
4. 調整設定，按「輸出影片」，等進度跑完後下載

影片只在自己的電腦上處理，不會上傳到任何地方。

## 開發過程中的幾個決定

- 一開始只偵測一個人，多人影片會一直跳到別人身上，所以改成讓使用者點選，再用「離上一格最近的人」一路追蹤
- 團體影片人一多、兩個人交錯時，追蹤會跳到別人身上，所以除了位置，也比較身體大小，並依移動方向預測下一格的位置；另外加了「準確模式」，可以換成比較大的偵測模型
- 想追蹤的人不一定一開頭就出現，所以加入手動關鍵影格：人還沒出現前由自己決定畫面，出現後再交給自動追蹤
- 原本跟丟一陣子後會放寬條件去找人，結果容易改跟到別人；改成選好的人就鎖定，不見時畫面停在原地，由使用者決定要加關鍵影格或重新選人
- 多人影片裡，只靠位置和身體大小還是會跳到靠很近的人身上，所以再加上「衣服顏色」：記住選的人上半身和大腿的顏色，顏色差太多就不當作同一個人；跟丟後也只接回顏色很像、而且附近沒有其他相似的人
- 畫面直接跟著人移動會很晃，所以加上平滑，參數是自己拿影片一組一組試出來的
- 曾經做過音樂重拍偵測和卡點放大，實際用下來覺得抓到的重拍不符合需求、效果也不自然，所以拿掉了
- 預覽很順但輸出的影片會卡，查了之後發現是邊播邊錄會掉格，改成一格一格處理再組成影片
- 用 Safari 測試時發現濾鏡沒效果、輸出沒聲音：濾鏡改成自己計算每個像素的顏色；聲音則改成直接把原影片裡的聲音搬過來，不重新編碼

## 目前的限制

- 目前適合 1～3 人的影片。人很多的團體影片，追蹤容易跳到別人身上，之後再優化
- 如果大家穿一樣的衣服，工具比較難分辨誰是誰，跳錯時可以在那個時間點重新點選

## 使用的技術與開源套件

- [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)（Google，Apache-2.0）：偵測人體骨架
- [mp4-muxer](https://github.com/Vanilagy/mp4-muxer)（Vanilagy，MIT）：把畫面和聲音封裝成 mp4
- [mp4box.js](https://github.com/gpac/mp4box.js)（GPAC，BSD-3-Clause）：在 Safari 讀出原影片的聲音
- WebCodecs：瀏覽器內建的影片、聲音編碼
- 純 HTML／CSS／JavaScript，不需要安裝任何東西
